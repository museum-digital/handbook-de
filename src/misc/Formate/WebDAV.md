# WebDAV

WebDAV ist eine Erweiterung des HTTP-Protokolls, mit der sich Dateien über das Netz nicht nur abrufen, sondern auch ablegen und verwalten lassen – grob vergleichbar mit FTP. Viele Betriebssysteme und Dateimanager können WebDAV-Freigaben wie ein Netzlaufwerk einbinden.

Bei museum-digital dient WebDAV dazu, Importdaten selbstständig auf den Server zu laden. Berechtigte Nutzende (Benutzerrolle „Museumsdirektor“ sowie Administratoren) generieren sich dazu in den [Kontoeinstellungen](../../musdb/Benutzerkonto/Kontoeinstellungen.md) auf dem Reiter „WebDAV“ ein eigenes, automatisch erzeugtes Passwort – das normale musdb-Passwort wird für die Schnittstelle nicht verwendet. Anschließend lassen sich die Daten mit einem beliebigen WebDAV-Client (etwa [WinSCP](https://winscp.net/eng/docs/lang:de) unter Windows oder dem Standard-Dateimanager der Gnome-Oberfläche unter Linux) auf den Server übertragen.

Wie ein solcher selbst durchgeführter Import abläuft, beschreibt die Seite [Importe selbst durchführen](../../import/importe-selbst-durchfuehren.md).

Weitere Informationen finden sich auf der [Wikipedia-Seite zu WebDAV](https://de.wikipedia.org/wiki/WebDAV).
